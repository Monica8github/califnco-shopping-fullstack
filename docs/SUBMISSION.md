## Suggested project description

Administrators manage catalogue, dealer decisions, fulfillment and service requests. A resumable daily workflow selects an in-stock product, generates a caption and image, and publishes through the official Instagram API when account permissions are configured. The repository includes 60 demo SKUs, tests, n8n exports and deployment instructions. Live-service limitations are disclosed in the verification record.
